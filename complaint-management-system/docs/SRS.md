# Software Requirements Specification

## Purpose
Centralized platform for submitting, tracking, assigning and resolving complaints.

## Actors
- User: submits and tracks complaints.
- Staff: processes complaints and updates status.
- Admin: oversees complaints and dashboard statistics.

## Functional requirements
Authentication, complaint creation, category/priority selection, tracking, staff processing, status updates, comments and administration.

## Non-functional requirements
Security, responsive UI, REST API, relational integrity, modularity and maintainability.
